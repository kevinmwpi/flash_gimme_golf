Flash Golf audio audition

Every sound is synthesized live with the Web Audio API. Click anything to unlock audio. The code between the PORT BOUNDARY comments is src/view/audio.ts (ARCH.md 1.10 AudioSystem surface plus the extra members listed in AUDIO.md section 1). The "HUD mute" button mirrors the three HUD states.

Shot and ball

ballHit scales with power (pitch, brightness, level). Bounces are per BounceSurface and ignore impacts under strength 0.08.

Mechanics

Each mechanic has its own timbre family so it can be identified blind: spring = boing, bumper = pinball ding, sand = shuffle, fan = air loop (+ "whff" on entry), colour gate = electric bzzt (blocked) / zwip (passed), switch = click + confirm, bridge = wooden slide.

Turns, results, campaign

Each player owns a note (P1 red = C5, P2 blue = G5). Medal jingles share one motif and add notes as the medal improves. Sequence buttons go through handleEvents() with real SimEvent shapes.

UI and online

Hover plays only for pointerType === 'mouse' and for keyboard focus (:focus-visible); taps on touch never hover.

Music bed

Generative, C major, 84 BPM, Cmaj7 - Am7 - Fmaj7 - G6 (two bars each), no drums. "title" = pad + bass; "play" adds sparse pentatonic plucks. Hidden tabs switch the scheduler to a 2.5 s lookahead / 1 s interval; a catch-up clamp skips missed beats instead of stacking them.

Debug (not shipped in Settings)

Settings ships mute + music toggle + one volume slider only. Bus trims exist for mixing sessions via setBusDb().
